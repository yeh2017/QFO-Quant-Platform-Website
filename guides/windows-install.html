Windows Setup

Windows 首次安装与常见错误

首次运行的目标只有三个：环境可用、项目完整解压、首次启动脚本执行成功。

一、安装前准备

  • Windows 10 或 Windows 11。
  • Python 3.12 或更高版本，安装时勾选 Add Python to PATH；本次在 Python 3.14 环境验证。
  • Node.js 22.12 或更高版本，适用于 v1.0.3 更新后的前端工具链。
  • 保持网络可用，首次运行需要下载 Python 和 Node.js 依赖。

二、正确下载与解压

  1. 从 QFO 最新 Release 下载稳定版 ZIP。
  2. 完整解压到独立文件夹，不要直接在压缩包预览窗口中运行。
  3. 优先使用不含中文、空格和特殊符号的短路径，例如 D:\QFO。

首次运行：双击 run_first_time.bat。它会检查环境、创建 Python 虚拟环境、安装前后端依赖并启动服务。安装完成后的日常启动使用 run_quick_start.bat。

三、常见错误与处理

现象原因与处理
Python not found重新安装 Python 3.12+，勾选 Add Python to PATH；安装后关闭并重新打开启动窗口。
Node.js 不存在或版本过低安装 Node.js 22.12+，完成后重新运行首次启动脚本。
电脑安装了多个 Python从 v1.0.3 起，脚本会优先使用有效的本地虚拟环境，再通过 Python 启动器和 PATH 寻找 Python 3.12+。检查启动窗口显示的实际解释器路径。
UnicodeDecodeError: 'gbk'旧 pip 按 GBK 读取 UTF-8 依赖文件。升级到最新稳定版，使用修复后的 UTF-8 安装流程；单纯更换镜像不能修复编码错误。
funding 或 vulnerabilities 提示funding 是赞助提示，不影响启动；vulnerabilities 是依赖审计结果，需要评估。不要直接运行 npm audit fix --force；使用最新稳定版并保留完整审计输出反馈。
依赖下载很慢或失败通常是网络连接或软件源临时异常。保持项目文件不动，网络恢复后再次运行 run_first_time.bat。
Failed to resolve 或 getaddrinfo failed安装时无法解析软件源域名。从 v1.0.4 起，脚本依次尝试阿里云、腾讯云和官方 PyPI。若都失败，先检查网络和 DNS，或切换到手机热点，再从原目录运行 run_first_time.bat。不必先删除虚拟环境或数据库。
双击后窗口立即关闭确认文件已经完整解压；在文件夹地址栏输入 cmd，再运行脚本以保留错误信息。
页面打开但没有数据安装已经完成。进入设置页填写自己的 Tushare Token，再到数据中台执行同步。
端口被占用关闭此前启动的 QFO、Python 或 Node.js 窗口，然后重新启动；不要同时运行多份项目。

跨电脑复制与数据保留

建议在目标电脑重新下载稳定版，避免直接复用原电脑的 backend/.venv 和 frontend/node_modules。保留数据时，先关闭 QFO 并备份，按数据迁移教程复制数据库，再运行首次启动脚本。不要为了重建环境删除数据库或本地配置。

四、提交问题前准备

如果仍然失败，请记录 Windows 版本、Python 版本、Node.js 版本、项目解压路径、完整错误截图，以及 backend/logs/ 中的启动日志。Token、API Key 等敏感信息必须遮挡或删除。
